      How the data is collected

      Reading the numbers

      Downloads. npm counts are monthly. crates.io totals are all time; recent counts are available in project details. The overview includes all packages, even those without a listed project.

      Freshness. The API is normally cached for an hour at the edge. Refreshing checks the endpoint again; it does not force a new upstream collection. Unavailable sources show a state instead of zero.

      * Active users. An activity proxy based on update-check requests over 30 complete UTC days, including CI and repeat checks. The count is not deduplicated people or installations. Unverified, incomplete, or stale usage is labeled instead of shown as a user count.

      Privacy and hosting. This page loads static files from GitHub Pages and the public JSON snapshot from our Bunny-hosted metrics endpoint. It uses no page analytics, cookies, external fonts, or browser storage.
